# PixelCrew — Floor 42 Swarm Commands Reference

Complete reference for all subcommands available under `/pixelcrew <command>` or direct `/<command>`.

---

## 1. `/assemble <prompt>` (Aliases: `/craft`, `/sprint`, `/ship`)
**Assigned Agent**: All Personas (Full Swarm)  
**Description**: Runs the complete multi-agent sprint pipeline from brief to verified code synthesis, visual review, and Playwright E2E tests.

---

## 2. `/blueprint <prompt>` (Aliases: `/shape`, `/spec`, `/plan`)
**Assigned Agent**: UX Planner & Lead Architect  
**Description**: Formulates UX section topologies, user journeys, schema contracts, and compiles a dynamic DAG task graph *before* writing code.

---

## 3. `/boss-fight <issue>` (Aliases: `/fix`, `/debug`, `/repair`)
**Assigned Agent**: Security Sentinel, QA & Frontend  
**Description**: Targeted swarm bug blitz to isolate root causes, synthesize atomic repair tasks, and verify with Playwright E2E checks.

---

## 4. `/manifest [--dry-run]` (Aliases: `/document`, `/doc`)
**Assigned Agent**: Lead Orchestrator & Creative Director  
**Description**: Reverse-engineers active repository components, styles, and routes into full `DESIGN.md` design system documentation and `PRODUCT.md` specifications.

---

## 5. `/retrofit [--dry-run]` (Aliases: `/extract`, `/tokens`)
**Assigned Agent**: Design System Architect  
**Description**: Scans project files and extracts recurring UI elements, color literals, and typography rules into centralized Tailwind tokens and CSS variables.

---

## 6. `/render` (Aliases: `/critique`, `/review-ui`)
**Assigned Agent**: Anti-AI Visual Critic  
**Description**: Executes a 6-dimension visual rubric review scoring Originality, Hierarchy, Typography, Layout, Brand, and AI Slop Penalty ($\ge 8.5/10.0$).

---

## 7. `/8bit` (Aliases: `/delight`, `/retro`, `/joy`)
**Assigned Agent**: Creative Director & Motion Specialist  
**Description**: Injects retro arcade Web Audio API chimes, CRT phosphor scanline toggles, and tactile micro-interactions.

---

## 8. `/overdrive` (Aliases: `/fx`, `/extreme`)
**Assigned Agent**: Motion & Frontend SRE  
**Description**: Injects GPU-accelerated WebGL/Canvas shaders, interactive terminal console, and live hardware HUD telemetry meters.

---

## 9. `/chromatic [palette]` (Aliases: `/colorize`, `/palette`)
**Assigned Agent**: Design System Architect  
**Description**: Injects curated HSL color tokens, dark mode elevation surfaces, and atmospheric accent tiers with ultra-high contrast (17.5:1).

---

## 10. `/typeset [preset]` (Aliases: `/typography`, `/fonts`)
**Assigned Agent**: Design System Architect  
**Description**: Applies mathematical fluid `clamp()` typography scales and editorial/geometric font pairings with tight optical tracking.

---

## 11. `/bento [section]` (Aliases: `/layout`, `/grid`)
**Assigned Agent**: UX Planner & Frontend  
**Description**: Reorganizes section into 12-column asymmetric Bento topologies with dynamic vertical rhythm and zero horizontal overflow.

---

## 12. `/de-slop [section]` (Aliases: `/clarify`, `/clean-copy`, `/copy`)
**Assigned Agent**: Content Strategist & UX  
**Description**: Strips generic AI marketing clichés (*"Unlock the power of next-gen AI"*) and injects grounded, technical value propositions.

---

## 13. `/sentinel` (Aliases: `/harden`, `/secure`, `/defense`)
**Assigned Agent**: Security Sentinel & Backend  
**Description**: Enforces RFC 7807 error envelopes, Zod schema validation, sliding-window rate limiting, and OWASP security headers.

---

## 14. `/audit` (Aliases: `/sre-audit`, `/quality`)
**Assigned Agent**: QA Automation & Performance SRE  
**Description**: Runs deep technical audits: WCAG 2.1 AA/AAA accessibility compliance, Core Web Vitals profiling (LCP < 0.6s), and Playwright E2E smoke tests.

---

## 15. `/warp` (Aliases: `/optimize`, `/perf`, `/speed`)
**Assigned Agent**: Performance SRE & Token Engine  
**Description**: Configures Next.js Streaming SSR, asset minification, and AST symbol graph extraction for 72% context reduction across LLMs.

---

## 16. `/polish` (Aliases: `/ship-ready`, `/finalize`)
**Assigned Agent**: Frontend Engineer & QA  
**Description**: Performs a final shipping readiness pass: token alignment, TypeScript compilation check, CSS cleanup, and visual consistency tuning.

---

## 17. `/calibrate [viewport]` (Aliases: `/adapt`, `/responsive`)
**Assigned Agent**: Responsive Specialist  
**Description**: Calibrates layout, padding, font scales, and tap targets for seamless viewing from 360px mobile up to 4K ultra-wide.

---

## 18. `/onboard` (Aliases: `/first-run`, `/empty-states`)
**Assigned Agent**: UX Planner & Frontend  
**Description**: Builds interactive zero-data empty states, progressive feature tours, and clear user activation paths.

---

## 19. `/office [--port 4747]` (Aliases: `/live`, `/dashboard`, `/preview`)
**Assigned Agent**: Floor 42 Visual Office Lead  
**Description**: Boots Floor 42 real-time startup office visual dashboard (`http://localhost:4747`), live SSE telemetry stream, and site preview iframe.

---

## 20. `/roster [spawn|list]` (Aliases: `/crew`, `/agents`, `/squad`)
**Assigned Agent**: Lead Orchestrator  
**Description**: Inspects active Floor 42 workstations, assigned tasks, sprite animations, and multi-agent health metrics.

---

## 21. `/doctor` (Aliases: `/diagnose`, `/health`)
**Assigned Agent**: Lead Orchestrator  
**Description**: Diagnoses environment health, local LLM provider availability (Claude Code, Cursor, Codex, Grok, Gemini), and API keys.

---

## 22. `/sync [--dry-run]` (Aliases: `/sync-providers`, `/mirror`)
**Assigned Agent**: Capability Lead  
**Description**: Synchronizes workspace skills across all detected IDE directories (`.claude`, `.cursor`, `.agents`, `.kiro`, `.opencode`, `.hermes`, `.pi`, etc.).
