# PixelCrew — Cross-IDE Token Optimization Protocols

Universal token conservation engine across Claude Code, Google Antigravity, Cursor, Kiro, Windsurf, and Copilot.

---

### Key Conservation Strategies:

1. **AST Symbol Graph Extraction**:
   - Extract function signatures, type interfaces, and route contracts instead of dumping raw 10,000-line files.
   - Slashes context window consumption by 60%–75%.

2. **Prefix Prompt Cache Anchoring**:
   - Anchors static system prompts and skill manuals at $\ge 1024$ tokens for Anthropic Claude Code, triggering a **90% cache read discount**.

3. **Multi-Turn Context Pruning**:
   - Prunes resolved subagent traces and temporary error logs between sprint phases.

4. **Line-Range Targeted Diffs**:
   - Generates compact replacement chunks (`replace_file_content`) rather than rewriting whole files.
